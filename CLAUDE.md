## Git / GitHub

- Origin tego repo to `https://github.com/zmariusz963/lotyzr.git` — to jest **żywy deployment** (GitHub Pages pod `https://zmariusz963.github.io/lotyzr/`).
- Użytkownik potwierdził (2026-08-05), że mam **commitować i pushować zmiany na GitHub automatycznie, bez pytania o potwierdzenie za każdym razem**. Nie trzeba więc pytać przed `git push` w tym repo.
- Mimo to: unikaj `git push --force` bez wyraźnej prośby, i unikaj commitowania plików, które wyglądają na sekrety/dane wrażliwe.
- Commity mogą być zwięzłe (1-2 zdania, po polsku, opis "dlaczego" a nie "co").
